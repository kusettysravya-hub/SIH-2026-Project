A full-stack, presentation-ready web platform developed for the **Smart India Hackathon** addressing the problem statement: **Hybrid Quantum Machine Learning Platform for Early Disease Detection**.

The platform implements a unified, fair-benchmarking research system comparing **Classical Machine Learning** (Logistic Regression, Random Forest) and **Quantum Machine Learning** (PennyLane Variational Quantum Circuits) on identical held-out test splits. The primary demonstration use case is **Type 2 Diabetes Risk Screening** utilizing the National Institute of Diabetes and Digestive and Kidney Diseases (NIDDK) benchmark dataset.

---

## ⚠️ Medical Research & Screening Disclaimer

> **IMPORTANT:** This application is an experimental research and screening-support prototype developed strictly for scientific exploration and computational benchmarking. **It is not a medical diagnostic tool.** Results generated by Classical or Quantum Machine Learning models are probabilistic risk estimates and must never be used as a substitute for professional medical diagnosis or clinical advice.

## Key Features

1. **Executive Overview Dashboard**:
   - Live architectural status indicators for Classical ML, Quantum VQC, and Dataset status.
   - Interactive 5-stage data lifecycle flowchart (Ingestion → Preprocessing → Hybrid Training → Evaluation → Screening).
   - Real-time backend connection heartbeat with PennyLane quantum simulator readiness.

2. **Real-Time Patient Risk Screening**:
   - Dynamic clinical parameter input form with reference ranges, validation, and demo presets (Low Risk, Pre-diabetic, High Risk).
   - Support for switching between **Quantum VQC (4-Qubit)**, **Logistic Regression (Baseline)**, and **Random Forest (Ensemble)**.
   - Live inference output with risk level categorization (Low / Moderate / High), probability gauge, model latency (ms), model confidence margin, and feature impact breakdown (Bloch sphere rotation angles for Quantum, coefficients for Classical).

3. **Empirical Model Comparison Hub**:
   - Multi-metric side-by-side comparison (Accuracy, Precision / PPV, Sensitivity / Recall, F1-Score, Training Latency).
   - Interactive Recharts bar charts comparing actual test performance.
   - Dual 2×2 Confusion Matrices visualizing True Positives, False Positives, True Negatives, and False Negatives.
   - Methodology & fairness disclosure explaining identical held-out splits and dimensionality adaptation.

4. **Interactive Dataset Management**:
   - Preloaded with the official Pima Indians Diabetes dataset (768 patient records, 8 clinical features, 1 binary outcome).
   - CSV file drag-and-drop uploader with schema validation, row minimums, and 10 MB size guards.
   - Feature inspection table showing missing values, physiological zero-value analysis, and cohort class balance pie charts.

5. **Visual Methodology & Architecture**:
   - Comprehensive pedagogical explanation of Bloch sphere Angle Embedding ($R_y$ single-qubit rotations).
   - Parameterized Variational Quantum Circuit (VQC) ansatz with circular CNOT entangling gates and Pauli-Z expectation value readout.
   - Clean handling of physiological missing zero-values without test-set data leakage.

6. **SIH Project & Future Scope**:
   - Hackathon project context, objectives, limitations, and physical NISQ QPU deployment roadmap.
